Faire une capture d’écran sous Windows 11

10 minGuide détaillé

Windows 11 permet de capturer une zone, une fenêtre, tout l’écran ou même une courte vidéo sans installer de logiciel. Voici les méthodes les plus utiles et où retrouver le résultat.

Dans ce tutoriel
  • La méthode la plus pratique : Windows + Maj + S
  • Où est la capture ?
  • Capturer directement tout l’écran
  • Enregistrer une vidéo de l’écran
  • Si le raccourci ne fonctionne pas

La méthode la plus pratique : Windows + Maj + S

  1. Préparez l’écran à capturer.
  2. Appuyez simultanément sur Windows + Maj + S.
  3. L’écran s’assombrit et une barre apparaît en haut.
  4. Choisissez : rectangle, forme libre, fenêtre ou plein écran.
  5. Sélectionnez la zone. La capture est copiée dans le Presse-papiers.
  6. Cliquez sur la notification qui apparaît pour annoter, recadrer ou enregistrer.

Où est la capture ?

Après Windows + Maj + S, la capture est d’abord dans le Presse-papiers. Vous pouvez la coller avec Ctrl + V dans Word, Outlook, Paint, Teams ou un autre logiciel.

Si vous ouvrez la notification de l’Outil Capture d’écran et cliquez sur Enregistrer, vous choisissez vous-même le dossier et le nom du fichier.

Capturer directement tout l’écran

  • Impr. écran : selon votre configuration, ouvre l’Outil Capture ou copie l’écran.
  • Windows + Impr. écran : sur de nombreux PC, enregistre automatiquement une image dans Images → Captures d’écran.
  • Alt + Impr. écran : copie seulement la fenêtre active dans le Presse-papiers.

Enregistrer une vidéo de l’écran

Ouvrez Outil Capture d’écran depuis Démarrer, passez en mode vidéo, cliquez sur Nouveau puis encadrez la zone à enregistrer. Lancez l’enregistrement et arrêtez-le quand vous avez terminé.

Confidentialité
Avant une capture ou une vidéo, masquez les e-mails, noms, mots de passe, notifications et informations personnelles visibles.

Si le raccourci ne fonctionne pas

  • Ouvrez directement Démarrer → Outil Capture d’écran.
  • Vérifiez que la touche Windows fonctionne.
  • Sur certains claviers portables, la touche Impr. écran nécessite la touche Fn.
À retenir
Pour envoyer une capture rapidement, Windows + Maj + S puis Ctrl + V dans le message est souvent le chemin le plus rapide.

Questions fréquentes

Pourquoi Windows + Maj + S ne crée-t-il pas immédiatement un fichier ?

Ce raccourci place d’abord la capture dans le Presse-papiers et affiche une notification. Vous pouvez la coller directement avec Ctrl + V ou ouvrir la notification pour l’enregistrer.

Comment capturer un menu déroulant ?

Ouvrez l’Outil Capture d’écran avant d’afficher le menu et utilisez le délai de capture lorsqu’il est disponible. Cela vous laisse le temps d’ouvrir le menu avant la prise.

Une capture d’écran suffit-elle comme preuve ?

Une capture peut être utile pour documenter un problème, mais elle peut être modifiée et ne remplace pas toujours un fichier original, un journal système ou une preuve certifiée.

Checklist de fin

  • ☐ Aucune donnée sensible n’est visible
  • ☐ Le bon type de capture a été utilisé
  • ☐ L’image est lisible
  • ☐ Le fichier a été enregistré au bon endroit
  • ☐ Le destinataire peut comprendre ce qu’il doit regarder
