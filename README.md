# TechFacile

Site GitHub Pages avec contenus modifiables via Pages CMS.

## Administration
1. Aller sur https://app.pagescms.org/
2. Se connecter avec GitHub.
3. Installer/autoriser Pages CMS sur le dépôt `titanxxx505/techfacile`.
4. Ouvrir le dépôt et modifier les tutoriels ou les textes du site.

Les modifications sont enregistrées dans GitHub et GitHub Pages republie le site automatiquement.
