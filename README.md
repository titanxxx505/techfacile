# TechFacile

🌐 **Site : https://titanxxx505.github.io/techfacile/**

TechFacile est un site gratuit de tutoriels informatiques accessibles, avec une identité visuelle inspirée des forêts de sapins brumeuses.

Cette version contient **32 tutoriels** dans **8 thématiques** : Windows, Internet & Cloud, Bureautique, Sécurité, Dépannage, Smartphone, IA & outils et Matériel.

## Newsletter

La page d’accueil inclut une inscription par thèmes avec confirmation par e-mail (double opt-in). Le backend gratuit à déployer avec Google Apps Script se trouve dans `newsletter-backend/Code.gs`. Les instructions sont dans `INSTALLATION_NEWSLETTER.md`.

## Publication GitHub Pages

Le site est entièrement statique et contient un fichier `.nojekyll`. Publiez la branche `main` depuis `/ (root)`.
