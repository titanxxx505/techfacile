# TechFacile

TechFacile est un site de tutoriels informatiques pensé pour rendre l’informatique plus simple, plus claire et plus accessible.

Le site propose des guides pratiques, expliqués étape par étape, sur des sujets du quotidien : Windows, Internet, bureautique, sécurité numérique et dépannage.

## Objectif du site

L’objectif de TechFacile est d’aider les utilisateurs à comprendre ce qu’ils font sur leur ordinateur, et pas seulement à reproduire des manipulations.

Les tutoriels sont conçus pour être :

- simples à suivre ;
- accessibles aux débutants ;
- structurés étape par étape ;
- orientés vers des problèmes concrets ;
- attentifs aux bonnes pratiques de sécurité.

## Catégories

Le site est organisé autour de plusieurs grandes thématiques :

- **Windows** : réglages, optimisation et astuces ;
- **Internet** : web, e-mail, cloud et partage de fichiers ;
- **Bureautique** : Word, PDF et outils de productivité ;
- **Sécurité** : mots de passe, comptes et protection des données ;
- **Dépannage** : résolution de problèmes matériels et logiciels.

## Exemples de tutoriels

Parmi les premiers tutoriels disponibles :

- Comment accélérer un PC Windows trop lent ;
- Créer des mots de passe vraiment sécurisés ;
- Partager un fichier avec Google Drive.

De nouveaux tutoriels pourront être ajoutés régulièrement.

## Design

TechFacile utilise une identité visuelle inspirée d’une **forêt de sapins brumeuse** : tons verts naturels, atmosphère douce, photos de forêt et mise en page épurée.

Le site est responsive et peut être consulté sur ordinateur, tablette et smartphone.

## Administration du contenu

Le contenu du site peut être administré via **Pages CMS**, connecté au dépôt GitHub.

L’accès à l’interface d’administration est protégé par l’authentification GitHub. Les utilisateurs publics du site ne peuvent pas modifier les contenus.

L’interface permet notamment de gérer :

- les tutoriels ;
- les titres et descriptions ;
- les catégories ;
- les durées et niveaux ;
- le contenu éditorial du site.

## Technologies utilisées

Le site repose principalement sur :

- HTML5 ;
- CSS3 ;
- JavaScript ;
- GitHub Pages pour l’hébergement ;
- Pages CMS pour l’administration des contenus.

## Hébergement

Le site est publié gratuitement avec **GitHub Pages**.

Le dépôt contient les fichiers nécessaires au fonctionnement du site, notamment `index.html` pour la page d’accueil.
