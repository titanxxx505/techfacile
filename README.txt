TECHFACILE — SITE DE TUTORIELS INFORMATIQUES

Fichiers :
- index.html : page d'accueil
- styles.css : mise en forme
- script.js : recherche, filtres et menu mobile
- tutoriel-pc-lent.html : exemple de tutoriel
- tutoriel-mots-de-passe.html : exemple de tutoriel
- tutoriel-google-drive.html : exemple de tutoriel

Pour tester le site : ouvrez index.html dans un navigateur.
Pour le publier : vous pouvez déposer ces fichiers sur un hébergement statique, un serveur web ou les adapter à WordPress/Shopify/Webflow.
