Choisir les applications par défaut dans Windows

6 minDébutant

Windows permet d’associer un type de fichier ou un protocole à l’application de votre choix.

1. Ouvrir les paramètres

Allez dans Paramètres > Applications > Applications par défaut.

2. Rechercher une application

Sélectionnez par exemple votre navigateur ou votre lecteur PDF préféré.

3. Modifier les associations

Cliquez sur un type de fichier ou un protocole puis choisissez l’application voulue.

4. Tester

Ouvrez un fichier concerné pour vérifier que la nouvelle association s’applique.

À retenir
Évitez de modifier toutes les associations d’un coup : changez uniquement celles dont vous avez réellement besoin.
